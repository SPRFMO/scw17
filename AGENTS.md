# AGENTS.md

## Purpose

This repository contains working papers, presentations, meeting reports,
figures, tables, and supporting material for the SPRFMO Scientific Committee
Working Group (SCW17).

This repository is a reporting and communication repository, not the primary
location for scientific model development.

Primary scientific analyses are conducted in companion repositories such as:

* jmMSE
* jjm
* FLjjm
* benchmark repositories

Whenever possible, results should be reproduced from those repositories rather
than recreated here.

---

## Role of This Repository

SCW17 serves as the integration layer between:

* scientific analyses
* benchmark outputs
* MSE outputs
* working papers
* Scientific Committee documents
* presentations and meeting materials

The repository should contain sufficient information to regenerate submitted
working papers and supporting figures.

---

## Scientific Integrity

Do not modify scientific conclusions without explicit instruction.

Do not alter:

* benchmark results
* operating model assumptions
* management procedure definitions
* performance metric definitions
* reference points

unless specifically requested.

If discrepancies are identified, document them rather than silently correcting
them.

---

## Writing Style

Documents are written for:

* SPRFMO Members
* Scientific Committee participants
* external reviewers
* fisheries scientists

Use:

* clear technical language
* concise descriptions
* evidence-based statements

Avoid:

* advocacy language
* unsupported conclusions
* speculative interpretations

---

## Citations and Traceability

All figures, tables, and numerical results should be traceable to:

* jmMSE outputs
* jjm outputs
* benchmark documents
* referenced working papers

Whenever possible, record the source file and analysis date.

---

## Figures and Tables

Prefer automated generation.

Avoid manually editing figures.

Avoid manually modifying numerical values in tables.

If a table is edited manually, document the reason.

---

## Working Papers

When drafting working papers:

* maintain consistency with previous SPRFMO terminology
* use accepted benchmark nomenclature
* preserve operating model names
* preserve management procedure names
* preserve reference point definitions

Do not rename established scenarios.

---

## Review Process

Before finalizing documents:

1. Verify consistency with source analyses.
2. Verify figures and tables update correctly.
3. Verify references compile successfully.
4. Verify document numbering is correct.
5. Verify conclusions match underlying analyses.

---

## Definition of Done

A document is complete when:

* all figures render correctly
* all tables update correctly
* references compile
* numerical values are traceable
* conclusions are supported by results
* document is ready for Scientific Committee review
